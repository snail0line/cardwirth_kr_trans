# CardWirth 한글화 툴

CardWirthPy 시나리오(XML)의 일본어 텍스트를 추출 → 한국어 번역 입력 →
실행 가능한 한글 시나리오로 재삽입(repack)하는 로컬 웹 에디터.

> 📖 **시나리오 구조·흐름을 어떻게 분석하는지**(번역 대상 판별, 화자/말투, 쿠폰 분기 조건,
> 이벤트 흐름 모델)는 **[SCENARIO_ANALYSIS.md](SCENARIO_ANALYSIS.md)** 참조.

## 빠른 시작

의존성 없음(순수 Python stdlib). Python 3.10+ 면 됩니다.

```bash
cd cardwirth_kr_trans      # 클론/압축해제한 프로젝트 폴더
python -m app.server
```

> Windows 는 `run.bat` 더블클릭으로도 실행됩니다.

브라우저가 자동으로 `http://127.0.0.1:8765` 를 엽니다.

1. **📁 폴더**(`Summary.xml` 이 있는 XML 시나리오 폴더) 또는 **📦 .wsn**(패키지 파일) 로 열기.
   경로를 직접 입력하고 Enter 쳐도 됨.
2. 좌측 **파일** 목록에서 파일 선택 → 일본어(좌) 보고 한국어(우)에 입력 (포커스 벗어나면 자동 저장).
   플래그/스텝/쿠폰 등 **식별자는 번역하지 않음**(원문 유지 — 이름 매칭으로 게임 로직이 돌아감).
3. **🔍 검색**(원문/번역으로 문장 찾기), **📖 용어집**(반복 문구 일괄 적용),
   **🌐 번역 초안(DeepL/Azure) / CSV 일괄**(아래 참조) 등으로 작업.
4. **한글 시나리오 내보내기** → 출력 폴더(또는 `.wsn`) 지정 → 번역 적용 + 이미지/사운드 등
   에셋까지 복사된 완전한 시나리오 산출. CardWirthPy(KOR) 의 Scenario 에 넣으면 실행됨.

진행 상황은 `projects/<폴더명>.json` 에 자동 저장됩니다. 다시 같은 폴더를 열면 이어서 작업합니다.
원본 시나리오가 바뀌어 재추출해도 원문(JP) 기준으로 기존 번역을 보존합니다.

## 편집 화면 편의

- **게임 줄바꿈 미리보기**: 번역칸을 클릭하면 실제 CardWirth 메시지창처럼 줄바꿈이 어떻게
  되는지 고정폭으로 미리 보여줍니다. 한 줄 최대 43칸(전각 기준), **그림이 뜨는 메시지는 33칸**
  으로 좁아지며(왼쪽에 그림 자리 표시), 세로 **7줄**을 넘으면 잘리는 지점을 붉은 선으로 표시합니다.
  → 번역문이 게임에서 어디서 넘어가는지 보고 줄바꿈을 다듬을 수 있습니다.
- **↺ 원문으로**: 각 메시지의 번역/초안을 버리고 원문으로 되돌립니다(다시 번역하고 싶을 때).
- **말투 변형 묶음**: 같은 대사의 말투(口調)별 변형은 한 묶음으로 접혀 표시됩니다.

## 자동 번역 초안 / 일괄 작업 (초벌용, 선택)

- **🌐 번역 초안**: 빈 번역칸을 자동 번역(JA→KO)으로 일괄 채웁니다. 엔진은 두 가지:
  - **DeepL** (기본, 품질 우선 — 무료 50만 자/월): 처음 한 번 **DeepL API 키**를 입력해
    저장하면 됩니다(이 PC의 `tools/.deepl_key` 에만 저장, 깃에는 안 올라감).
    무료 키(`:fx` 로 끝남)는 자동 인식되고, 모달에서 이번 달 사용량/잔여를 확인할 수 있습니다.
  - **Azure** (물량 보조 — 무료 200만 자/월, 품질은 DeepL 보다 한 단계 아래):
    Azure 포털에서 **Translator 리소스(가격 계층 Free F0)** 를 만들고 "키 및 엔드포인트"의
    키와 지역(예: `koreacentral`)을 모달에 저장하면 됩니다(`tools/.azure_key` 에만 저장).
    `$…$` 변수·`#` 치환코드는 이름 치환 기법으로 보호되며, 보호 복원에 실패한 문장은
    빈 칸으로 남습니다 — 이후 DeepL 초안을 돌리면 그 빈 칸만 채워집니다.
    사용량은 조회 API 가 없어 이 툴에서 보낸 분량 기준으로 자체 집계해 보여줍니다.
  - 공통: **현재 파일만 / 전체 시나리오** 단위로 생성. 기본은 빈 칸만 채우고(덮어쓰기 옵션 있음),
    제어기호·내부명은 건너뛰며, 동일 문장은 1번만 번역(쿼터 절약). 대사 괄호 `「」`,
    문두 들여쓰기(전각 공백), `$…$` 변수 참조는 원문 그대로 보존합니다(게임 레이아웃·변수가 안 깨짐).
  - `tools/compare_deepl_azure.py` 로 두 엔진의 번역을 나란히 비교한 CSV 를 만들 수 있습니다.
- **⬇ / ⬆ CSV 일괄 입출력**: 모든 원문을 CSV로 내보내 외부 번역기(스프레드시트 등)로 돌린 뒤
  다시 가져올 수 있습니다. 키 없이도 가능. (`tools/translate_deepl.py` 로 CSV를 DeepL에 돌리는 것도 지원)
- ⚠️ 자동 번역 결과는 **초벌**입니다. 그대로 쓰지 말고 검수하세요.

## 번역 대상 분류

- **자유 텍스트**: `<Text>`(대사), `<Description>`, 제목·카드 이름 `<Name>`, 선택지 라벨(`@name`) 등 → occurrence 별 번역.
  `%상태변수%` 로 대사에 실제 표시되는 플래그/스텝의 **표시값**(True/False/Value 문장)도 번역 대상
  ("변수값" 분류 — 사용처↗/정의↗ 로 상호 이동 가능)
- **식별자(번역 X)**: 플래그/스텝/쿠폰/가십/시나리오/키코드/링크 이름 → 이름 매칭으로
  게임 로직이 돌아가므로 **원문 그대로 유지**(번역하지 않음). 용어집 치환도 자유 텍스트에만 적용
- **제외**: 파일 경로(`path`/`ImagePath`), 표시 안 되는 플래그 표시값(ＴＲＵＥ/ある 등), id/좌표/숫자,
  에어리어/배틀/패키지 자체 이름(플레이어 비노출 내부명), 제어코드·치환자뿐인 메시지(읽기전용 표시)

## 구조

```
app/
  schema.py   번역 대상 분류 규칙(자유 vs 식별자)
  xmlio.py    XML 입출력 + 문서순서 슬롯 순회(extract/repack 공유)
  extract.py  XML 폴더 → 번역 프로젝트
  context.py  화자/말투 판정
  flowcond.py 이벤트 흐름 추적 → 대사별 도달 조건(쿠폰 분기 등)
  flow.py     씬 흐름 그래프(플로우차트)
  terms.py    반복 용어/캐릭터명 감지 + 일괄 적용
  textcodec.py 줄바꿈(\n)·이스케이프 디코드/인코드
  repack.py   번역 적용 + 에셋 복사 → 완전한 시나리오
  project.py  프로젝트 JSON 영속화 + 재추출 머지
  server.py   로컬 웹 서버(stdlib http.server) + 폴더 선택 다이얼로그(tkinter)
web/          브라우저 에디터(index.html / app.js / style.css)
SCENARIO_ANALYSIS.md  시나리오 구조·이벤트 흐름·조건 분석 방법(★)
```

## 입력 포맷

- **`.wsn` 패키지 / XML 시나리오 폴더**: 바로 열립니다.
- **classic 바이너리(`.wsm`/`.wid`) 시나리오**: 그대로는 안 됩니다. 먼저 **CWXEditor** 등으로
  `.wsn` 또는 XML 로 변환한 뒤 열어주세요.
